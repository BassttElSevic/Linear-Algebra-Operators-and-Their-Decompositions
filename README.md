# 线性代数：抽象结构 —— 算子及其分解

我自己写的线性代数讲义。内容是有限维向量空间上**算子**及其各种分解：从不变子空间出发，
经特征结构、上三角化、对角化、Jordan 标准型、实向量空间的复化，再进入内积空间，
讨论伴随、正规算子、自伴算子、谱定理，最后到极分解与奇异值分解。

原稿是 Markdown，排版成 LaTeX 教材（XeLaTeX 编译）。

## 目录结构

```text
线代教材/
├── 线性代数-抽象结构-算子及其分解.md   ← 唯一的手写源稿，改这个文件
├── tools/md2tex.py                     ← Markdown → LaTeX 转换器
├── tex/
│   ├── main.tex                        ← 主文件：扉页、体例说明、目录、后置索引
│   ├── preamble.tex                    ← 版式：字体、配色、章节样式、各种彩色盒子
│   ├── body.tex                        ← 全书骨架（自动生成）
│   └── chapters/                       ← 每章一个 .tex（自动生成）
├── output/线性代数-算子及其分解.pdf     ← 成品
└── Makefile
```

## 编译

```bash
make          # 转换 + 编译（三遍 xelatex），结果放进 output/
make tex      # 只做 Markdown → LaTeX
make pdf      # 只编译
make clean    # 清理中间文件
```

依赖：TeX Live（ctex、tcolorbox、titlesec、unicode-math、Libertinus 字体）、
Noto Serif / Sans CJK SC、Python 3。

## 修改内容的正确姿势

`tex/chapters/*.tex` 与 `tex/body.tex` **是自动生成的，不要手改**——下次 `make` 会覆盖。

* 改数学内容 → 改 `线性代数-抽象结构-算子及其分解.md`
* 改版式（颜色、字体、盒子、页眉）→ 改 `tex/preamble.tex`
* 改扉页 / 体例说明 / 前后置页 → 改 `tex/main.tex`
* 改「哪些标题算定义、哪些算定理」→ 改 `tools/md2tex.py` 里的 `CLASSIFY` 表

## 转换规则

| Markdown | 排版结果 |
| --- | --- |
| `#` 一级标题 | 一章；其中三个总览标题排成 `\part` 整页，第一个排成「绪论」 |
| `##` 二级标题 | 一节；若标题登记在 `CLASSIFY` 中，则整节正文变成**定义／定理／命题**彩色盒子 |
| `###` 三级标题 | 小节；「证明思路」变灰色证明块，「理解」变紫色旁注块；父节若已成盒子则自动提升为节 |
| `> 引用` | 金色**要点**块 |
| `$$ … $$` | 行间公式 |
| `-` / `1.` | 列表（含缩进公式的续行） |

## 版面约定

知识块统一风格：**满宽饱和色标题条（白字粗体）+ 细同色边框 + 极淡底色 + 方角**。

| 颜色 | 含义 |
| --- | --- |
| 藏青蓝 #000080 | 定义 |
| 暗红 #8B0000 | 定理 |
| 墨绿 #006B3C | 命题、性质、刻画 |
| 灰色竖线 #3F4A5A | 证明或证明思路，段末有小方块 |
| 靛紫 #4B0082 | 「理解」——对形式化内容的翻译 |
| 琥珀金 #8A5A00 | 一节的要点 |
| 藏青蓝大框 | 每一「部分」开头的导读 |

定义、定理、命题在同一章内共用一套编号（如 `定义 12.1`、`定理 12.2`），
书末按类别各有一份一览表。
